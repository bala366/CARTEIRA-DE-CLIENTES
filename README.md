# Carteira Casarão do Campo — Android V2

- Menu rebaixado para não ficar engolido pela barra superior do celular.
- Menu em MAIÚSCULAS e horizontal com rolagem, sem quebrar palavras.
- Dashboard em MAIÚSCULAS, com cartões e espaçamento melhores.
- 258 clientes carregados na base inicial.
- Lápis para editar cliente e botão NOVO CLIENTE mantidos.
- PDFs e movimentações mantidos.
- Banco atualizado automaticamente da V1 para V2.

Build GitHub: Ubuntu, Temurin Java 17, Gradle 8.9.
